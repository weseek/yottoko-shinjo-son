# 実装タスク

## Task Format Template

- [x] 1. mailto URI 生成関数の実装
  - `buildMailtoHref` 純粋関数を `page.tsx` に追加する
  - 件名として「【Arcana】予約完了のお知らせ」を設定する
  - 本文にアクティビティ名・アクティビティ ID・実施日時（`formatDateTime` を使用）・予約者名を含める
  - `to` フィールドは空にする（宛先はユーザー自身が入力する）
  - 件名・本文のすべての文字列を `encodeURIComponent` でエンコードする
  - `entryName` が `null` の場合は予約者名の行を本文から省略する
  - `endDate` が `null` の場合は終了日時の表示を省略する
  - _Requirements: 2.2, 2.3, 2.4, 2.5_

- [x] 2. 完了画面への「メールで送る」ボタン追加
- [x] 2.1 ボタンの条件表示とリンク生成
  - `activity` が取得できた場合にのみボタンを含むセクションを描画する
  - `activity` が `null` の場合はボタンを表示しない
  - スクリーンショット案内の直下にボタンを配置する
  - タスク 1 で実装した `buildMailtoHref` の戻り値を `<a>` タグの `href` に設定する
  - Client Component への変換は行わない（Server Component のまま）
  - _Requirements: 1.1, 1.2, 1.3, 3.1, 3.2, 3.3, 3.4_

- [x] 2.2 アクセシブルな UI の実装
  - タッチターゲット最小サイズ 48px を確保する（`min-h-12` クラスを使用）
  - フォントサイズは `text-base`（16px）以上で表示する
  - コントラスト比 4.5:1 以上を満たすカラートークン（`var(--color-secondary-400)` 等）を使用する
  - スクリーンリーダーで認識できるよう、視覚的なラベルテキスト「メールで送る」を `<a>` タグ内に記述する
  - ボタンの近くに補足テキスト「メールアプリが開きます」を表示する
  - Tailwind クラスと `[var(--color-xxx)]` 任意値を使用し、インラインスタイルを避ける
  - _Requirements: 4.1, 4.2, 4.3, 4.4, 4.5_

  - `endDate` あり・なしで日時表示が切り替わることを確認する
  - 日本語文字が `encodeURIComponent` で適切にエンコードされることを確認する
  - `to` フィールドが空（`mailto:?` で始まる URI）であることを確認する
  - _Requirements: 2.2, 2.3, 2.4, 2.5_

  - `activity` が取得できない状況でボタンが非表示であることを確認する
