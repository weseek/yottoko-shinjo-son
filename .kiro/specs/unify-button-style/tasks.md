## Implementation Notes

- Task 5.4（fixing-accessibility）で、FilterButtonが色による選択状態表現の撤去に伴い`aria-pressed`も持たず状態を一切告知できていない点を検出。配色（要件5で確定済み）には触れず、`aria-pressed`をFilterButtonに追加する最小修正をユーザー承認の上で適用した（activity-filter-client.tsx）。
- Task 3.6: `OperationGuide.tsx`/`CapturedPhotoPreview.tsx`はAR非対応端末向けフォールバック体験（`HomeArFallbackExperience.tsx`）のクライアント側state（`showGuide`/`showPreview`）に応じて条件表示されるため、カメラ許可なしのcurl/SSR確認では実際のレンダリングを直接視認できなかった。lint/build/2回の独立コードレビューでクラス文字列の正しさを確認し、既に他画面で視覚確認済みの`buttonClassName`関数を再利用しているため視覚的リスクは低いと判断したが、実機（実際のカメラ許可フロー）での最終目視確認は未実施。
- タスク3.6のレビュー中、`pnpm build`が本環境のビルドキャッシュ破損（`_document`等のPageNotFoundError）で一時的に失敗する事象が複数回発生した。`.next`削除→再ビルドで解消する既知の一過性事象であり、コードの問題ではない。
- 2026-07-29: 実装完了後、ユーザー要望によりバリアント名を `secondary` から `outline` にリネーム。`button-variants.ts`・全呼び出し元7ファイル・`design-system.md`のコード識別子に加え、requirements.md/design.md/research.md/tasks.md内の日本語表記「セカンダリ」も「アウトライン」に統一した。旧JoinButton（本specで置き換え前）の`secondary-500/600`トークンおよび`"outline"|"solid"`という異なる意味の値を指す記述は履歴として残し変更していない。lint/buildで検証済み。
