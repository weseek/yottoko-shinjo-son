# Implementation Plan

- [x] 1. データモデル拡張
- [x] 1.1 ActivityImage モデルを追加し、Activity とのリレーションを構築する
  - Prisma スキーマに ActivityImage モデルを定義する（url, order, activityId, createdAt）
  - Activity モデルに images リレーションフィールドを追加する
  - ActivityImage から Activity へのカスケード削除を設定する
  - `prisma db push` でデータベースに反映し、`prisma generate` でクライアントを再生成する
  - _Requirements: 3.1_

- [x] 2. 訪問者向けレイアウトと一覧ページ
- [x] 2.1 activities 配下の共通レイアウトを作成する
  - 訪問者向けページ共通のレイアウトコンポーネントを作成する
  - ページメタデータ（タイトル）を設定する
  - セマンティック HTML 構造（main タグ）でコンテンツを囲む
  - 最小フォントサイズ 14px・行間 1.5 をベーススタイルとして適用する
  - WCAG AA 準拠のカラーコントラスト比を確保する
  - _Requirements: 5.1, 5.2_

- [x] 2.2 アクティビティ一覧ページを作成する
  - 公開中（PUBLISHED）および終了（CLOSED）のアクティビティをデータベースから取得する（DRAFT は除外）
  - 開始日の降順でソートする
  - 各アクティビティの画像リレーションを取得する（先頭画像をサムネイル用に使用）
  - 取得結果をカードコンポーネントに渡して描画する
  - 該当アクティビティが 0 件の場合、「現在公開中の体験メニューはありません」と空状態メッセージを表示する
  - スマートフォン表示に最適化したレスポンシブレイアウトでカードを配置する
  - _Requirements: 1.1, 1.2, 1.3, 1.4, 1.6, 1.7_

- [x] 2.3 (P) アクティビティカードコンポーネントを作成する
  - サムネイル画像（先頭画像）・タイトル・説明の抜粋（約 80 文字）・開始日を表示する
  - 画像が設定されていない場合、プレースホルダー画像を表示する
  - 画像に alt テキストとしてアクティビティタイトルを設定する
  - 終了済み（CLOSED）アクティビティを視覚的に区別する（透明度の低下と「終了」ラベル表示）
  - カード全体を詳細ページへのリンクとして機能させる
  - キーボードフォーカスが自然に当たるようにする
  - _Requirements: 1.3, 1.5, 2.1, 3.2, 3.4, 3.5, 5.3_

- [x] 3. 詳細ページと申込導線
- [x] 3.1 アクティビティ詳細ページを作成する
  - URL パラメータからアクティビティ ID を取得し、データベースから該当レコードを取得する
  - タイトル・説明（全文）・開始日・終了日を表示する
  - 関連する全画像を表示順（order 昇順）で表示する
  - 画像が設定されていない場合、プレースホルダーを表示する
  - 各画像に alt テキストとしてアクティビティタイトルを設定する
  - 一覧ページへの戻る導線を提供する
  - 存在しないアクティビティまたは下書き（DRAFT）の場合は 404 ページを表示する
  - 不正な ID パラメータ（非数値）の場合も 404 ページを表示する
  - _Requirements: 2.1, 2.2, 2.6, 2.7, 3.3, 3.4, 3.5, 5.4, 5.5_

- [x] 3.2 ステータスに応じた申込導線を実装する
  - 公開中（PUBLISHED）のアクティビティには「参加してみる」ボタンを表示する
  - ボタンタップで申込ページへ遷移するリンクを設定する
  - 終了（CLOSED）のアクティビティでは「参加してみる」ボタンを非表示にし、終了済みであることを表示する
  - _Requirements: 2.3, 2.4, 2.5, 4.1, 4.2_

- [x] 3.3 (P) 申込ページのプレースホルダーを作成する
  - 申込ページのルーティングパスを確保する
  - 「準備中です」等のメッセージを表示する
  - 一覧ページへの導線を提供する
  - _Requirements: 4.3_

- [x] 5. UI リデザイン（一覧ページ）
- [x] 5.1 ActivityCard を Badge・JoinButton を用いたカードデザインに更新する

  - Badge コンポーネントでステータス表示
  - 「詳しく見る」（outline）・「参加してみる」（solid、PUBLISHED 時のみ）ボタンを配置

- [x] 5.2 一覧ページ見出し・レイアウトを更新する
